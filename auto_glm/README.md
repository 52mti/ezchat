# AutoGLM 迁移层

本目录从旧 `autoglm` 工作台迁移的是通用协议，不包含 Android Agent、ADB 或无障碍代码。

执行链路：`GPT 规划 JSON 原子节点 -> AutoGLM 根据截图返回一个 0~999 动作 -> 机械臂适配器执行 -> 截图验证`。

`RobotActionAdapter` 仅直接执行滑动、等待。点击和双击必须由具体 App 注入 `point_resolver`：模型千分比坐标只能作为候选，局部模板/OCR/找色复核后才能返回实际点击点。文字输入和返回也必须由具体 App 显式注入处理器，避免模型在物理机械臂方案中猜测坐标。

当前目录尚未接入心遇主流程。接入时应当：

1. 本地模板、OCR、颜色规则优先。
2. 仅在本地定位失败时，让 AutoGLM 执行一个短原子任务。
3. 将模型点击限制在该控件已配置的匹配范围内，并用局部规则复核。
4. 每次动作后重新截图，确认页面状态或画面变化；失败保存中文诊断并停止或回退。

API Key 仅从运行配置传入 `AutoGLMConfig`，不得写入配置文件、日志或提交到仓库。
